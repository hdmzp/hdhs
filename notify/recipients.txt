# 텔레그램 알림 수신자 - 한 줄에 한 사람: 채팅ID  받을 알림들  #이름
#
# 받을 알림 (영어나 한글 아무거나):
#   food    식품     일반식품·건강식품 방송 리스트
#   celeb   셀럽     어제 셀럽PGM 운영상품
#   fashion 패션     의류·언더웨어·잡화/주얼리 방송 리스트
#   living  리빙     리빙/주방·가전 방송 리스트
#   beauty  미용     미용 방송 리스트
#   brand:설화수     그 브랜드 방송이 있는 날 알림 (브랜드마다 하나씩)
#   admin   관리자   게스트 후보 같은 관리용 메시지를 받는 사람
# 알림을 하나도 안 적으면 food + celeb 을 받는다.
#
# 보통은 여기 적을 필요 없다: 받을 사람이 봇에서 START → 버튼으로 고르기 → 관리자가 승인하면 끝
# (worker/telegram-bot.js). 여기는 봇을 거치지 않고 직접 넣을 사람, 브랜드 알림, admin 표시용.
# 같은 ID 가 봇에도 있으면 봇에서 고른 알림을 쓴다 (admin·brand 는 여기 것 유지).
# 빼려면 그 줄을 지우거나 맨 앞에 # 를 붙인다.
#
# 예시:
# 123456789  fashion beauty brand:설화수  #김철수
